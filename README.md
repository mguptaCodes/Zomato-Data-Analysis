# Zomato Restaurant Data Analysis Dashboard

## Project Overview

This project analyzes Zomato restaurant data using Python and Power BI.
The dataset was cleaned and preprocessed using Python (Pandas), and an interactive Power BI dashboard was created to visualize restaurant ratings, votes, online ordering, table booking availability, restaurant types, and average cost.


## Objectives

- Clean and preprocess raw Zomato dataset
- Perform exploratory data analysis (EDA)
- Build an interactive Power BI dashboard
- Identify restaurant trends and customer preferences


## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplot
- Seaborn
- Jupyter Notebook
- Power BI
- CSV

## Dashboard Features

The Power BI dashboard includes:
- Restaurant Name Slicer
- Count of Votes by Restaurant Type
- Sum of Rating by Online Order
- Online Order by Restaurant Type
- Average Rating by Restaurant Type
- Count of Votes Gauge
- Average Rating Gauge
- Average Approximate Cost Map
- KPI Cards


## Key Insights

- Dining restaurants receive the highest number of votes.
- Average restaurant rating is approximately **3.63**.
- Restaurants offering online ordering have higher cumulative ratings.
- Dining restaurants dominate the restaurant categories.
- Average cost varies significantly across restaurants.


## How to Run This Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Zomato-Data-Analysis.git
```

### 2. Open the project folder

```bash
cd Zomato-Data-Analysis
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Jupyter Notebook

```bash
jupyter notebook
```

Open **Zomato.ipynb**.

### 5. View the Power BI Dashboard

Open

```
Zomato_Dasboard.pbix
```

using Microsoft Power BI Desktop.
